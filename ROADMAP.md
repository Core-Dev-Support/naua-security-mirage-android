# Roadmap

Куда движется NAUA Security Mirage. Голосуй за пункты через 👍 в Issues или предлагай своё через Feature Request.

## 🧪 В тестировании (v1.4.0, не выпущен)

- [ ] Продление подписки в приложении с датой окончания
- [ ] Проверка версий через серверный кэш (без лимитов GitHub API)
- [ ] Push о релизе: мгновенно при публикации + фоновая проверка раз в сутки
- [ ] Оценка узла по потерям и джиттеру, а не только по пингу

## ✅ Уже в релизе (v1.3.0)

- [x] VLESS + Reality, автовыбор сервера
- [x] Пул бесплатных узлов + платная Франция (Париж)
- [x] Split-tunneling: Per-App + свои домены + .ru напрямую
- [x] 2 Quick Settings плитки, уведомление со скоростью и пингом
- [x] Аккаунт (email + Google), подписка 40 ₽ без лимита устройств
- [x] Самообновление с проверкой подписи, скриншот-защита, журнал + логи туннеля
- [x] CI/CD: secret-scan → тесты → R8 → подпись v2/v3 → автопубликация

## 💡 Идеи (не обещания)

## 💡 Как предложить идею

1. Проверь [Issues](https://github.com/Core-Dev-Support/naua-security-mirage-android/issues) — может, уже предложено.

3. Опиши проблему → сценарий → ожидаемый результат.
