## 🛡 О проекте

**NAUA Security Mirage** — клиент защищенного сетевого туннелирования нового поколения на базе протокола VLESS и ядра Xray. Обеспечивает высокий уровень приватности, шифрование трафика в публичных сетях и удобный пользовательский опыт без навязчивой рекламы.

### ✨ Ключевые возможности
- **⚡ Высокая скорость и стабильность:** Поддержка современного протокола VLESS с минимальной задержкой и эффективным использованием полосы пропускания.
- **🔒 Политика No-Logs:** Никакого сбора истории посещенных сайтов, DNS-запросов и личной информации.
- **🛡 Self-Healing Integrity:** Криптографическая привязка расшифровки сетевой конфигурации к SHA-256 цифровой подписи релиза.
- **🔄 Раздельное туннелирование (Per-App Proxy):** Локальный выбор приложений для направления через защищенный туннель.
- **🎨 Премиальный интерфейс:** Адаптивная тёмная и светлая палитры, 3D-стили кнопок (Standard, Cyber Earth, Quantum), высокая контрастность.
- **🔔 Удобство управления:** Фоновый Foreground Service с переключателями в системной шторке Android без всплывающих окон.
- **📊 Диагностика в реальном времени:** Встроенный пинг-тест и замер скорости соединения.
