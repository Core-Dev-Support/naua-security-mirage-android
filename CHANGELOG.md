# Changelog

Все значимые изменения проекта. Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/).

## [Unreleased] — v1.4.0 🧪 (в тестировании, не выпущен)

Заметки: [docs/releases/v1.4.0.md](docs/releases/v1.4.0.md).

### Добавлено
- Продление подписки прямо в приложении: кнопка оплаты меняется на «Продлить» и показывает дату окончания текущей подписки.
- Уведомление о новой версии: фоновая проверка раз в сутки + мгновенный push при публикации релиза на GitHub.
- Выбор узлов по трём метрикам: пинг + потери + джиттер (чистый канал побеждает «быстрый, но рваный»).

### Исправлено
- Проверка обновлений больше не упирается в лимиты GitHub API («повторите позже»): версии раздаёт сервер с кэшем.
- Журнал: долгий тап по кнопке подключения больше не вешает интерфейс и не роняет приложение с `OutOfMemoryError` (логи Xray читались целиком), файлы журналов Xray подрезаются.
- Вход через Google: обмен кода авторизации на сессию больше не отваливается «в молчание». Причина отказа теперь показывается в сообщении, попытка обмена повторяется при временной ошибке, а вход не сбрасывается, если начать его заново, пока старый ещё открыт в браузере.

### Добавлено
- Продление подписки с выбором срока: 1 месяц — 30 ₽, 3 месяца — 80 ₽ (−11%), 6 месяцев — 150 ₽ (−17%), 1 год — 250 ₽ (−32%).
- Пробный день: один бесплатный день платного узла во Франции. Решение о выдаче принимает сервер: пробник выдаётся один раз на аккаунт и один раз на устройство, повторный запрос отклоняет сама база.

### Изменено
- Кнопка «Поддержка» убрана: её содержимое переехало в меню кнопки «Telegram Канал / Поддержка / Бот» (канал, поддержка, бот). У «Поблагодарить разработчика (3 способа)» остались только донаты.
- Окно подписки теперь называет оба платных узла — Францию и Беларусь, а сумма показана как «от 30 ₽»: срок выбирается отдельным шагом.

### Убрано
- Режим «Доступ к ИИ» (обход блокировки Google AI через частный DNS): Google не отдаёт Gemini и AI Studio из России и Беларуси, обходные адреса оказались ненадёжными. Функция удалена целиком — вместе с переключателем, настройкой DNS для ИИ и правилами маршрутизации.

## [1.3.0] — текущий стабильный релиз

Заметки: [docs/releases/v1.3.0.md](docs/releases/v1.3.0.md).

### Добавлено
- Вход в аккаунт через Google, привязка подписки к аккаунту.
- Платная подписка: ЮMoney, 30 ₽ / 30 дней, без автосписаний.
- Выделенный сервер во Франции (Париж) + переключатель тарифов.
- Кнопки «Telegram-канал» и «Поддержка».
- Блокировка скриншотов и записи экрана (`FLAG_SECURE`).
- Логи туннеля в журнале событий.

### Изменено
- Кнопка «Поддержать проект» → «Поблагодарить разработчика».
- Убраны упоминания RuStore из приложения.
- Ускорены подключение и переподключение, исправлено зависание туннеля.

### Исправлено
- Бесплатный режим: сбои DNS, доступ к сервисам через туннель.
- Ряд уязвимостей приложения.
