# Security Policy

## Поддерживаемые версии

Активно поддерживается только последний релиз (`v1.4.x`). Обновляйся через
[Releases → Latest](https://github.com/Core-Dev-Support/naua-security-mirage-android/releases/latest).

| Версия | Статус |
| :--- | :--- |
| 1.4.x | ✅ поддерживается |
| 1.3.x | ⚠️ только критические фиксы |
| < 1.3 | ❌ не поддерживается |

## Как сообщить об уязвимости

**Не создавай публичный Issue или PR с деталями уязвимости.**

Напиши приватно:

- 📧 Email: **coredevsupport@gmail.com**, тема `Security: краткое описание`
- 💬 Telegram (для ускорения): https://t.me/News_And_Updates_Apps

В письме укажи:

1. Версию приложения / коммит.
2. Шаги воспроизведения (PoC — приветствуется).
3. Возможный impact (утечка трафика, обход оплаты, RCE и т.д.).
4. Свои контакты для уточнений.

## Что дальше

- Подтвердим получение в течение **72 часов**.
- Оценим серьёзность, подготовим фикс и выпустим обновление.
- При желании — публично поблагодарим в release notes (только с твоего согласия).

## Что уже встроено

- `secret-scan` в CI: падает при секретах в коде.
- Проверка подписи APK (v2/v3) в CI.
- Self-Healing Integrity: конфиг расшифровывается только при подлинной подписи.
- `FLAG_SECURE` против скриншотов/записи экрана.
- DNS строго внутри туннеля, токены — в `EncryptedSharedPreferences`.
